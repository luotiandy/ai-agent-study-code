# w1-cli · W1 收官整合版(D7)

流式输出 × 多跳工具循环的终端 Agent。六天零件的整合产物:流式打字机、5 个工具、
工具过程可视化、成本面板、多模型配置。

## 运行

```bash
# 仓库根目录
pnpm start-w1d7
```

## 功能

- 流式多轮对话(打字机输出、历史保留、Shift+C 中断且保留已生成内容)
- 工具调用:get_weather / calculator / list_dir / read_file / write_file
- 多跳任务:工具结果可以继续驱动下一轮工具调用(如「北京温度×3」= 查询 → 相乘 → 作答)
- 工具过程可视化(🔧 行)+ 成本面板(/usage、/pricing)+ 会话预算软警报
- 安全护栏:文件工具限制在项目目录内(路径穿越防护)、calculator 白名单、单文件 40KB 上限

## 命令

| 命令 | 作用 |
| --- | --- |
| /help | 命令列表 |
| /history | 打印当前消息数组 |
| /clear | 清空历史(保留 system) |
| /usage | 累计 token 与费用 |
| /pricing | 模型单价表 |
| /tools | 模型可见的工具定义 |
| /exit | 退出 |

## 演示任务

> 扫描这个项目,统计各代码文件的行数,把报告写到 report.md

预期多跳序列:list_dir → read_file × N → calculator(汇总)→ write_file(报告)→ 总结。

## 已知边界

- 中断语义:Shift+C 只中断「当前这轮」流,已生成的半截回答会回填历史
- 工具轮数预算 5 轮,耗尽后强制自然语言收尾(防无限循环)
- 报告写入位置以运行时 cwd 为项目根(仓库根目录)
