## 组内三次结果相似度

### Factual：字符 bigram Dice 相似度

计算方式：

1. 转小写，删除空白与标点；
2. 取字符 2-gram 集合；
3. 计算 `Dice = 2 × |交集| / (|A| + |B|)`。

| 温度 | run 1 ↔ run 2 | run 1 ↔ run 3 | run 2 ↔ run 3 | 平均 |
|---:|---:|---:|---:|---:|
| 0 | 0.387 | 0.447 | 0.453 | **0.429** |
| 0.7 | 0.608 | 0.552 | 0.589 | **0.583** |
| 1.5 | 0.477 | 0.504 | 0.393 | **0.458** |

观察：三组都共享同一段核心解释模式，但 `T=0` 的三次回答在细节选择和句式上差异较大。`T=0.7` 本组的三次回答表层文本最接近。

### Creative：精确集合 Jaccard

计算方式：

1. 每个 run 的 10 个名称视为一个集合；
2. 名称转小写后比较；
3. 计算 `Jaccard = |交集| / |并集|`。

| 温度 | run 1 ↔ run 2 | run 1 ↔ run 3 | run 2 ↔ run 3 | 平均 |
|---:|---:|---:|---:|---:|
| 0 | 1 / 0.053 | 4 / 0.250 | 1 / 0.053 | **0.118** |
| 0.7 | 3 / 0.176 | 1 / 0.053 | 4 / 0.250 | **0.160** |
| 1.5 | 0 / 0.000 | 0 / 0.000 | 0 / 0.000 | **0.000** |

观察：该指标只统计完全一致的名称。`T=1.5` 组内没有精确重复，多样性最高；但 `T=0` 和 `T=0.7` 的组内精确重合度也都不高，因此不能仅凭这三次样本得出“温度越高组内多样性单调上升”的强结论。
